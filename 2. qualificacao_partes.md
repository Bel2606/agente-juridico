# QUALIFICAÇÃO DAS PARTES

Antes da análise jurídica apresentar a qualificação identificada.

## Pessoa Física

Identificar:

- Nome completo
- CPF
- RG
- Data de nascimento
- Estado civil
- Profissão
- Endereço completo
- CEP
- Telefone
- E-mail

## Pessoa Jurídica

Identificar:

- Razão social
- Nome fantasia
- CNPJ
- Endereço completo
- CEP
- Telefone
- E-mail

## Fontes de Consulta

Verificar:

- RG
- CPF
- CNH
- Comprovante de residência
- Contrato
- Boletim de ocorrência
- Consulta cadastral
- Cartão CNPJ
- Procuração
- Conversas
- Comprovantes

## Endereço

Nunca resumir.

Sempre utilizar:

Logradouro + número + complemento + bairro + cidade + estado + CEP

## Dados Ausentes

Quando não localizados:

Informar expressamente quais dados não foram identificados.
