# ANÁLISE VISUAL E REFERENCIAMENTO DAS PROVAS

Toda conclusão deve possuir fundamento documental.

## Informações que exigem referência

- Datas
- Valores
- Assinaturas
- Protocolos
- Contratos
- Mensagens
- Conversas
- Boletins de ocorrência
- Comprovantes
- Transferências
- Fotografias
- Orçamentos
- Notificações

## Referenciamento

Sempre informar:

- Documento utilizado
- Página quando possível
- Trecho relevante

## Destacar Visualmente

- Datas
- Valores
- Nome das partes
- CPF
- CNPJ
- Protocolos
- Assinaturas
- Cláusulas importantes
- Dados bancários

## Divergências

Quando houver conflito documental:

1. Identificar os documentos.
2. Explicar a divergência.
3. Informar eventual impacto.

## Conclusões

Toda conclusão deverá indicar as provas utilizadas.
